1. Introduction

Template Name: Cryptrix PWA

Cryptrix PWA is a premium, beautifully designed Progressive Web App (PWA) template tailored for clean, professional, and app-like mobile experiences. Our mission is to make using this template completely seamless for both beginners and professional developers.

This documentation exactly explains how to use the ready-to-go Main File or, optionally, compile the Source Code from scratch if you are a developer.

Key Features

  • Progressive Web App (PWA) ready
  • Stunning, modern, and clean UI design
  • Fully responsive layout built for all devices
  • Built with Tailwind CSS v4
  • Clean, beginner-friendly coding structure
  • W3C valid HTML code
  • Cross-browser compatibility

2. Folder Structure (Very Clear)

When you download and extract the ZIP file from the marketplace, you will see three main folders:

  • documentation/

    This folder contains the help file you are reading right now.

  • cryptrix-Main File/

    (Ready-to-use version) This folder contains the final HTML, CSS, and JS files. NO build tools are required for this folder. It is fully functional out of the box.

  • cryptrix-Source Code/

    (For Developers) This folder contains the raw development files (Webpack, package.json, Tailwind config). You only need this folder if you plan to compile custom source code using build tools.

3. Installation / Usage Guide (Crucial for Non-Developers)

👉 Note: NO npm install, NO node.js, and NO build tools are required to use the Main File!

To use the template without any technical setup, follow these simple steps:

  1. Download and extract the template zip file to your computer.
  2. Open the cryptrix-Main File folder.
  3. Double click the index.html file. It will successfully open in your browser.
  4. Open the HTML files in your favorite text editor (e.g. VS Code, Notepad++, Sublime).
  5. Edit the content (text, links, images) to match your website.
  6. Upload the entire contents of the cryptrix-Main File folder to your web server/hosting via FTP.

4. Customization Guide

How to Edit Text

Open any .html file from the cryptrix-Main File folder using a text editor. Find the text you want to change (for example, a heading or paragraph) and simply type your new text. Save the file and refresh your browser.

How to Change Images

All template images are located inside the assets/img/ (or similar) directory. To change an image, place your new image in that folder and update the <img src="..."> tag in your HTML file to match the new image's name.

Where CSS & JS Files Are Located

The main styles are located in the css directory, and standard scripts are located in the js directory inside the cryptrix-Main File. You can safely open these layout files to append custom styles and scripts.

5. Developer Guide (Optional Source Code)

👉 Important: These steps are entirely optional. Use this section ONLY if you are an advanced developer looking to recompile properties using Webpack and Tailwind CSS.

The cryptrix-Source Code folder contains package.json and Webpack configurations. Here is how to use it:

  1. Ensure that Node.js is installed on your machine.
  2. Open your Terminal / Command Prompt and navigate to the cryptrix-Source Code directory.
  3. Run the following command to download all dependencies: 
    npm install
  4. To launch the local dev server and watch for live changes, run: 
    npm run dev
  5. To compile the final, minified production assets, run: 
    npm run build

Tools utilized: Webpack 5, Tailwind CSS v4, NPM.
