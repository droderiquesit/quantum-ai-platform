Algorik logo package

Includes full horizontal logo PNGs, transparent PNGs, icon-only PNGs, favicon.ico, Apple touch icon, Android Chrome icons, and site.webmanifest.

Recommended website usage:
- favicon.ico for browser favicon
- apple-touch-icon.png for iOS
- android-chrome-192x192.png and android-chrome-512x512.png in site.webmanifest
- algorik-logo-transparent-1024w.png for website header/hero use
