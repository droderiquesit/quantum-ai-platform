## How this was run

Every `#[test]` *added* between `b6ee74ad` and `a07946ac` in the territory was enumerated from
`git diff -U0 b6ee74ad..a07946ac` — **117 tests** (`qip-risk-engine` received none). For each, the
mutation its doc comment names was applied as an exact, once-only text substitution, the one test was
run (`cargo test -p <crate> --lib|--test <bin> -- <name>`), the result and first panic message
recorded, and the file rewritten from the saved original bytes; `git diff --quiet` confirmed the
restore on every row run in the main checkout. Where a doc named several mutations each got a row;
where it named none, the mutation deletes or neutralises what the test name claims. Rows prefixed
`fix-` are re-runs against the corrected test, done in a separate worktree (its `git diff` was
already dirty with the fix, so restoration there is the byte rewrite alone; each fixed suite was then
re-run green).

**Totals:** 117 tests; 175 mutation runs. Before fixes: 161 FIRED, 3 killed by abort (the
`decision_loop` watchdog, SIGABRT; the same tests pass in 0.09 s unmutated), 11 SURVIVED. Of the 11:
eight (in seven tests) were defects in the test and are fixed (each fix re-verified FIRED); one
(`hs-worldsalone`) was a doc naming a mutation the search's own re-check absorbs, corrected to one that
fires; one (`hs-survives`) is an equivalent mutation whose sibling fires; one (`A-learn-uncalibrated`)
the test's own doc already declares out of its reach and assigns to a `qip-twin` test. No
production defect was found: every survivor was a test that did not reach the code it named.
