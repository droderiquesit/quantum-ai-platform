## Judgement calls and what did not run

* **Invariants of undeployed code count as on the path.** The edge node, the deep brain and qip-agency's CLI are composition roots; a row whose requirement is something the code never does (a decision thread that never blocks on the fabric, a pass log that never waits, a model the cell refuses unless its manifest names it, a feature closure with no quantum crate) was graded on the root's own code, because the property holds for every build of it. A row whose requirement is something the code does (a ledger applying a journal, a node evaluating a distilled model, a fabric admitting a claim, a Spanner instance planned) was graded on whether a committed environment runs it.
* **Operator tools.** `qip agency shadow` and `scripts/fleet/dispatch.mjs goal` are run by a person; their behaviour is unconditional inside the command, and the rows (AGENCY-1146, AGENCY-9063, CICD-10115) say so. They were graded VERIFIED on that basis. A stricter reader who wants a scheduled caller would move them.
* **Not run to a verdict.** A whole-suite `cargo test -p qip-acceptance` under the CICD-9106 mutation was abandoned: `manifest_wiring` ran for over 20 minutes without finishing, so the mutation was re-run over the eight suites that read workflows (all passed with the refusal removed). `cargo test -p qip-deepbrain` was started whole for REFLEX-6075 and cut off by hand after its 205-test lib binary ran for five minutes with no verdict; its 14 integration binaries passed and the lib was run filtered to `learning` (31 passed). `cargo test --workspace` was not run: this audit edits no code and no test.
* **Terraform.** No terraform binary was installed; 1.9.8 was fetched from releases.hashicorp.com with its SHA256SUMS checked, to run LEDGER-8132's and SEC-9096's tftests.
* **Restores.** Every mutation was restored with `git checkout -- <file>` and `git diff --quiet` was checked; mutations that add a dependency also regenerate `backend/Cargo.lock`, which was restored the same way.
