## Readings of the bar applied

- Part 1, own-proof bullet: R12-TICK-1122 requires that a mutation change the replay digest. qip-sequencing tests fail the mutation but no digest-bearing suite (qip-acceptance tick_replay, qip-simulation-engine tick_replay, qip-deepbrain tick_desk) moves, so it stays PARTIAL.
- Part 1, hang: R12-REFLEX-5029's hang counts because `decision_loop.rs` has a test-level watchdog that aborts the binary (SIGABRT); the mutation is bounded.
- Part 2, emission vs collection: R12-OBS-9145/9147/9150 say Cloud Monitoring/Prometheus "carries" the series, but their own acceptance column asks only that a test drive the event and see the series move. Read as emission; kept COMPLETE. Ambiguous: a stricter reader moves all three.
- Part 3: R12-COVERAGE-5107, EVENT-5087, EVENT-5088 are gated prohibitions whose guard sits on the only creation or order path; R12-LEDGER-10197 and SEC-10021 are guards over committed Terraform. R12-EVENT-5087's "may create ... only where permitted" is a capability in form; read as a prohibition by its "only where" text (ambiguous).
- Part 4: R12-REFLEX-5030 (every slot consumed; ADR 0155 s11 declines value use) and R12-OBS-9161 (pod disruption withdrawn by a code comment) stay PARTIAL.
- R12-LEDGER-5016: qip-ledgerd's `apply_operation` is the shipped binary's default path (part 2 counts undeployed shipped binaries); producer shipping is a separate clause the requirement does not make.
