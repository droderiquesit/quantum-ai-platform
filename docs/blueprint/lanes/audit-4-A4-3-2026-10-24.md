## Judgement calls a sibling lane might grade differently

* **"Named test" is the row's `verification` plus its `evidence`, and the file named in its `current` text.** Where only an unnamed test caught the mutation the row was an OVERCLAIM (REFLEX-5029, RES-10130, REASON-3060, TICK-1122, WORLD-9027). Where a test named in `evidence` or `current` fired but the `verification` command does not run it, the row was kept VERIFIED and the stale command noted: REASON-3060's sibling REASON-3059 (reasoners fires on the engine's posterior; the kernel's panel-evidence line is caught only by an unnamed lib test), WORLD-1129 (verification is the qip-world-model crate; the cycle claim is the kernel test), SEC-9125 and SEC-9138 (the proving tests, admin_surfaces and identity_separation, are in `evidence`, not in `verification`). A stricter reader who grades on `verification` alone would move those four.
* **REASON-3060** is the closest call among the overclaims: the wiring (derive passes the observed moves to abduce) is pinned by symbolic_federation, and the ranking is pinned by a qip-world-model test. It was regraded because the acceptance is "mutating its core rule fails the test" and no named test fails when the ranking score is mutated.
* **Invariants of undeployed code count as on the path** (audit-3's rule, applied again): the edge node's pass, journal, sequencing and crossing rows were graded on the node's own code, which holds for every build. A row whose requirement is something the code does and that only a flag-off module provides was weighed against the environments.
* **SEC-10021** (certificates) was kept VERIFIED: the acceptance is an inspection of resource kinds, and the prohibition on uploaded certificates holds for every module in the tree. No committed environment instantiates any edge certificate (`public_edge` hostnames unset, `gitops_gateway_enabled = false`, `iap-edge` names no hostname), so none is issued today; a reader who needs "issued and rotated" to be true of a deployment would move it.
* **SEC-10023** is a project-scoped network firewall policy; the requirement's "inherited from the organisation" is R12-SEC-9131, as the row says, and the acceptance names "hierarchical/network firewall policy".
* **SEC-9138**: the infrastructure account holds `secretmanager.admin` and `cloudkms.admin` by a stated exception in `identity_separation.rs`; it is reachable from `infra.yml` on manual dispatch only and is not an agent identity, so the row stands.
* **TICK-2087**: the capacity probe's `DelayedFeed` amount replaced by zero survives the two named tests (they assert the probe's detail text and the presence of the `delayed_feed` condition), and the row states that the counterfactual twin reads bars without a feed delay. The acceptance (reads at decision time return only records with `known_at <= t`) is pinned and the `known_at` mutation fires, so the row stands.
* **REFLEX-7059**: the acceptance text names `qip-streaming/transport`; the cell links `qip-transport` for the mesh client by design (architecture.rs:866), so only `qip-streaming` is held.
* **RISK-4121** keeps the row's own caveat: the integration test lets the worst library world drive the reserve, so the counterparty arithmetic is pinned only by the named lib test (a_levered_book_does_not_survive_its_broker_and_an_unlevered_one_does), which fires.
* **RISK-4110**: `thesis_reliability`'s weakest-component rule (`reduce(f64::min)`) survived the two named tests; the requirement does not ask for weakest-of, so it was noted and not graded.
