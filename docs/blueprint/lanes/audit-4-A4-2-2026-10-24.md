## Judgement calls and what did not run

* **Undeployed binaries.** Per the lane bar, rows whose property is the code of a shipped binary (fabricd, ledgerd's store, the edge node, the CLI) were graded on that code; rows whose property needs an env- or tfvar-gated feed were graded on whether a committed environment turns the feed on. LEDGER-5016 is the row this cuts closest on: the treasury ledger entries are produced by the kernel by default, but the only drain is gated on QIP_FABRIC_URL. A sibling lane that grades ledgerd's own apply path as the behaviour would keep it VERIFIED.
* **Clauses withdrawn by the row.** FINOPS-10136 (reported, not just carried), MODEL-6021 (capital impact), OBS-9161 (pod disruption) and GCP-8119 (mesh and client breaker clauses) were graded OVERCLAIM on that rule. OBS-9161 is the weakest: the platform has no GKE workload, so a reader could call the clause vacuous.
* **Emission rows.** OBS-9145, 9147 and 9150 say 'Cloud Monitoring/Prometheus carries the metric'. The series is emitted on `/metrics` of a shipped binary and the unit check is met; nothing is shown to scrape it. They were kept VERIFIED on the unit check; a stricter reader would move them.
* **Weak `verification` fields.** FABRIC-7033, FABRIC-7053, QUANT-4028, GOV-9080 and MODEL-3091 name a `verification` command or evidence line that does not prove the property; the evidence-named test does, and it fired, so they were not regraded.
* **Terraform.** No terraform binary was installed; 1.9.8 was fetched from releases.hashicorp.com with its SHA256SUMS checked, to run modules/network (23 passed) and modules/observability (10 passed). `.terraform` directories are git-ignored.
* **Not run.** No whole-suite `cargo test -p qip-acceptance`, `-p qip-deepbrain` lib or `--workspace` was run for the mutations (`manifest_wiring` alone takes 20 minutes); mutations were run against the named suites and, where a survivor was recorded, a wider crate-level run. This audit edits no code and no test; the only files changed are the nine register rows, the regenerated docs and this report.
* **Restores.** Every mutation was restored with `git checkout -- <file>` and `git diff --quiet` was checked after it.
