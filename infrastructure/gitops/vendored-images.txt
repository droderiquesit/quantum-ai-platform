# Third-party images the platform adopts, mirrored into its own registry.
#
# Binary Authorization's default rule denies every image the platform's
# attestor has not signed, and that is the point of it — so a third-party
# controller can run here in one of two ways: an exemption pattern that
# admits its upstream repository unsigned for ever, or an adoption. This
# file is the adoption path: `.github/workflows/vendor.yml` copies each
# source digest into the environment's Artifact Registry byte-for-byte,
# proves the digest survived the copy, scans it with the same gate the
# platform's own images pass, and attests it with the same attestor. The
# admission policy stays exactly one rule with no holes, and "which foreign
# code runs in our cluster" is answered by this file's git history.
#
# Sources are named by digest, never by tag. A tag is whatever its owner
# says it is today; the digest is what was reviewed when the line was
# added. Moving to a new upstream version is a new digest in a new commit.
#
# Format: <source-ref-by-digest> <destination-path> <destination-tag>
# The destination lands at <registry>/<destination-path>:<destination-tag>
# in the target environment's registry. The tag is for humans browsing the
# registry; everything that matters references the digest.
